## 📚 Módulos do Curso

O programa da formação está dividido de forma cronológica e incremental, cobrindo desde os fundamentos até a publicação na App Store:

* **Módulo 1: Introdução ao Ecossistema**
  * Configuração do Xcode, entendimento das ferramentas Apple e ciclo de vida de desenvolvimento.
* **Módulo 2: Linguagem Swift**
  * Fundamentos da linguagem, variáveis, estruturas de controle, funções, POO e conceitos avançados.
* **Módulo 3: SwiftUI**
  * Construção de interfaces declarativas, componentes visuais, modificadores e gerenciamento de estado.
* **Módulo 4: Navegação e Fluxo de Telas**
  * Gerenciamento de rotas, tab bars, modais e transições entre telas de forma nativa.
* **Módulo 5: Arquitetura de Software**
  * Boas práticas de código, padrões de projeto aplicados ao iOS (como MVVM) e organização de pastas.
* **Módulo 6: Persistência de Dados**
  * Armazenamento local, cache, uso de UserDefaults e frameworks de banco de dados nativos.
* **Módulo 7: APIs e Notificações**
  * Consumo de serviços web (REST APIs), tratamento de JSON e implementação de Push Notifications.
* **Módulo 8: Recursos Nativos do iPhone**
  * Integração com hardware (como câmera, biometria/FaceID, localização e sensores).
* **Módulo 9: Testes**
  * Testes unitários e de interface (UI Tests) para garantir a estabilidade e qualidade do aplicativo.
* **Módulo 10: Publicação**
  * Processo de build, App Store Connect, criação de certificados e envio do app para a loja.
